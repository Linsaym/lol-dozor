# Архитектура LoL Dozor

| Модуль                                          | Ответственность                                                |
| ----------------------------------------------- | -------------------------------------------------------------- |
| `src/App.tsx`                                   | Обзор, маршрутизация по состоянию игры, настройки              |
| `src/Analytics.tsx`                             | Составы, расчёт матчапа и рекомендации по доступной истории    |
| `src/Draft.tsx`, `src/draft-recommendations.ts` | Выбор позиции и целей драфта, фильтры и ранжирование вариантов |
| `src/draft-data.ts`                             | Роль и механики чемпионов, объяснения контрпиков и связок      |
| `src/game.ts`, `src/live.ts`                    | Типизированный IPC, опрос клиента, загрузка статистики, ссылки |
| `src/catalog.ts`, `public/demo/`                | Каталог Data Dragon, кэш патча и офлайн-ресурсы                |
| `src/demo.ts`                                   | Изолированные демонстрационные составы, ранги и история        |
| `src-tauri/src/client.rs`                       | Поиск установки клиента, фаза игры и составы                   |
| `src-tauri/src/riot.rs`                         | Маршрутизация, кэш, лимиты Riot API и DPAPI                    |
| `src-tauri/src/lib.rs`                          | Команды Tauri, открытие браузера, восстановление окна          |

## Источники данных

- LCU обнаруживается через метаданные установок Riot Client в ProgramData и стандартный путь League of Legends. Токен lockfile используется только для HTTPS на loopback. Для Loopback API выделен отдельный HTTP-клиент, принимающий сертификат игрового клиента и запрещающий прокси и перенаправления.
- Во время выбора чемпионов Rust читает сессию драфта и доступные пики через LCU. Снимок передаёт позиции, открытые пики, видимые намерения союзников и баны. Номер драфта сохраняется до перехода в соответствующий активный матч, чтобы аналитика подхватила ручной выбор соперника.
- Модель драфта работает по локальному каталогу ролей, механик и отдельных пар способностей. Числа используются внутри ранжирования. Приложение показывает причины выбора, а пул пользователя хранится локально в настройках интерфейса.
- После начала игры Dozor использует локальные данные gameflow и Live Client Data. Запросы Riot API относятся к игрокам активного состава.
- Riot API использует платформенный маршрут для ранга и региональный для аккаунтов и истории. Статистика загружается по игрокам с ограничением частоты, кэшем и паузой по `Retry-After`. Срок кэша для профиля и списка игр 15 минут, для деталей матча один час. Developer API Key хранится в `riot-key.dpapi` в локальных данных приложения с шифрованием для текущего пользователя Windows.
- Data Dragon проверяется при запуске и каждые 30 минут. React запрашивает русские метаданные чемпионов, предметов и способностей с официального CDN и сохраняет последний каталог. Демо использует встроенный снимок патча и локальные изображения.
- Tauri разрешает IPC-команды только в окне `main`. Rust проверяет назначение внешних ссылок перед открытием системного браузера. Релизная политика CSP допускает ресурсы приложения и официальный CDN Data Dragon.

## Запуск и проверка

`npm run dev:desktop` открывает Vite через Tauri и WebView2. `npm run dev` запускает браузерный интерфейс с демонстрационным матчем по умолчанию. Для разработки используется порт 1420.

`npm run check` проверяет React и Rust. `npm run build:smoke` встраивает фронтенд в `src-tauri/target/debug/lol-dozor.exe`. Запустите этот файл, проверьте фазу клиента, затем переключитесь на демонстрацию и проверьте составы, выбор соперника и компактный режим. Для проверки статистики в активной игре нужен действующий Developer API Key.
